# One console per project, with linked exhibits

**Status:** accepted

**Context:** A project's visuals could live as one dashboard or as a page per artifact. Decided on console proposal `p-20261012-1900-console-topology`.
**Decision:** One console artifact per repository, forever, with the heavy visuals published as separate exhibits registered as rows on it.
**Alternatives:** A page per artifact — no single place to see what is waiting, and a second console splits the decision inbox.
**Consequences:** `.arty` holds exactly one `console` URL; exhibits are reached through the console's Maps & reports tab, never collected by hand.
